# 동물 디저트 카페 (시제품)

친구 1~4명이 동물 인형 요리사가 되어 디저트 카페를 운영하는 로블록스 협동 게임 시제품입니다. 동물 손님이 카운터 앞에 와서 말풍선으로 주문하면, 디저트를 만들어 손님 앞 자리에 내 줍니다(아이스크림·음료는 손에 든 채로, 와플·케이크는 쟁반에 담아서).

- 하루 영업은 DAY 1 120초에서 하루 +15초(최대 180초). DAY가 오를수록 새 메뉴·기구가 열리고 손님이 덜 기다리며 조금씩 바빠집니다. 손님 양은 인원이 처리할 수 있는 만큼입니다(메뉴마다 혼자 만드는 시간 어림 × 여유 ÷ 인원별 처리량 1/1.75/2.4/3배, `Config.Crowd`).
- 목표 매출은 없고 DAY는 항상 넘어갑니다. 판 돈은 **가게 금고**에 모이고(맨 위 바, 손님 머리 위에 +코인), 영업 중 쓴 **운영비**는 세어 두었다가 밤에 한꺼번에 냅니다.
  - 재료비: 재료 상자에서 꺼낼 때마다(찻잎·우유 1, 펄·반죽 2, 딸기 3), 아이스크림 콘·컵·한 층·토핑 1씩
  - 전기·가스: 기본(조명·냉장고, 영업 1초에 0.1) + 기구 한 번 쓸 때마다(아이스크림 기계·티 냄비 1, 와플 기계 2, 오븐 3)
  - 소화기 충전 15, 설거지 수도세 1, 쓰레기 봉투 1, 하루 월세 15
- 가게를 열며 **빚 600**을 지고 시작합니다. 밤마다 남은 빚에 이자 3%가 붙고, **상환금**(DAY 1 20, 하루 +5)이 자동으로 빠집니다. 상점 창에서 더 갚을 수도 있습니다.
- 월세·상환금은 한 명 늘 때마다 +30%입니다.
- 밤 정산: 금고에서 운영비 + 월세 + 상환금을 내고, 남은 **순수익을 인원수로 똑같이 나눠** 각자 지갑에 넣습니다(잔돈은 금고에 남아 다음 날 매출에 더함). 적자면 **각자 지갑에서 1/n씩** 메우고, 그래도 모자라면 **연체**(모자란 돈 + 연체료 20%가 빚으로)입니다. **3번 연체하면 파산**해서 DAY 1 아침부터 다시 합니다(지갑·빚·상점 단계도 처음으로).
- 밤 창에는 항목별 장부(무엇을 몇 번 썼고 얼마인지), 나눠 가진 돈, 빚 변화가 나옵니다. 30초 뒤 저절로 다음 날 영업이 시작되고, 모두 "준비"를 누르면 바로 시작됩니다.
- 개인 지갑은 상점에서 기구(와플 기계·티 냄비·조합대 추가)와 스킬(조리·조합 속도 등)을 사고 빚을 더 갚는 데 씁니다. 산 사람 지갑에서만 돈이 나가고 효과는 모두에게 적용됩니다.
- 아이스크림은 아이스크림 기계(E, 뒷줄 양 끝에 하나씩)에서 여는 창에서 그릇·맛(최대 3층)·토핑을 골라 만들고, 꺼낸 뒤 시간이 지나면 녹습니다.
- 조합대 F 버튼에는 지금 누르면 무엇이 만들어지는지(예: "밀크티 만들기"), 모자라면 무엇을 더 올리면 되는지(예: "우유 더 올리면 밀크티")가 뜹니다.
- 날마다 하나씩 새 규칙이 생깁니다(아침 창의 큰 카드, 영업 시작 때 화면 위에도 잠깐):
  - DAY 3 단체 손님: 일행과 함께 와서 한 자리에서 2~3개 주문, 다 내면 단체 보너스 30%
  - DAY 4 홀 테이블: 손님 일부가 홀에서 먹고 가고, 다 먹은 테이블은 E로 빈 그릇을 치워 쓰레기통(홀·주방)에 버려야 다음 손님이 앉음
  - DAY 5 골치 아픈 손님: 급한 손님(팁 2배), 주문을 바꾸는 변덕쟁이, 받은 걸 떨어뜨리는 덜렁이(다시 내면 팁 1.5배)
  - DAY 6 설거지: 빈 그릇은 버릴 수 없고 개수대(주방 왼쪽 앞)에 넣고 F 길게
- 다른 친구가 10초 안에 이어서 손님에게 내면 팀 콤보가 올라 콤보마다 코인 +3을 더 받습니다.
- 말 없이도 나눠 하게: 다른 친구 머리 위에 그 친구가 들고 있는 것이 작은 그림으로 뜨고, 마감하면 "오늘의 MVP" 카드(서빙왕·코인왕·아이스크림 장인·청소왕·불 끈 영웅)가 그 친구의 동물과 함께 나옵니다.
- 플레이어는 요리사 모자·앞치마 차림의 동물 인형입니다. "동물 고르기" 창에서 생김새와 능력을 보고 고릅니다. 주황 고양이·토끼·곰은 처음부터, 돼지(49)·강아지(79)·회색 고양이(99)·판다(149)는 **Robux 게임패스**로 사람마다 엽니다. 게임패스 id(`src/shared/AnimalLooks.luau`의 `pass`)가 0인 동안은 Studio에서만 무료로 열려 시험할 수 있습니다.
- 동물 능력(자기 행동에만): 주황 고양이 팁 +25%, 토끼 이동 +12%, 곰 익히기 12% 빠름, 돼지 아이스크림 60% 늦게 녹음, 강아지 F 길게 35% 빠름, 회색 고양이 익히기 22% 빠름 + 이동 +6%, 판다 이동 +10%·F 길게 20% 빠름·팁 +20%.
- 버튼(E·F 알약)은 캐릭터가 바라보는 쪽에서 가장 가까운 기구 하나에만 뜹니다. 기구 앞에 서서 그 기구를 보면 됩니다.
- 영업을 시작하면 홀 양옆 출입문이 열리고, 마감하면 닫힙니다.
- 효과음(코인·집기·주문·조합·불·설거지·카운트다운·성공/실패·클릭)과 이 게임용으로 직접 만든 뮤직박스 배경음악이 나옵니다. 소리는 로블록스 기본 소리(`rbxasset://sounds/…`)를 높낮이만 바꿔 써서 저작권 걱정이 없고, `Config.Sounds`·`Config.Music.trackId`에 Creator Store 소리 id를 넣어 바꿀 수 있습니다.
- 아침·밤 창의 "튜토리얼"은 연습 손님 두 명(바닐라 콘, 밀크티)으로 단계마다 화살표를 띄워 알려 줍니다. 코인은 들어오지 않습니다.

- 가게는 도시 한가운데 블록에 있습니다. 둘레에 차도·횡단보도, 길 건너에 파스텔 건물(1층 가게 간판·차양)이 늘어섭니다. 영업하는 동안 바깥은 맑은 아침 → 한낮 → 노을 → 해 질 녘으로 빛이 바뀌고(해 질 녘부터 가로등·창문에 불), 밤 정산 때는 어둡습니다. 가게 안은 조명으로 늘 같은 밝기입니다(`src/client/Outdoor.client.luau`).
- 새 메뉴·새 규칙은 영업이 시작될 때 화면 위에 잠깐 떴다가 스르륵 사라집니다.
- 최고 기록: 밤 정산을 무사히 넘길 때마다 "DAY N까지 버텼다"를 사람마다 기록하고, 아침·밤 창 오른쪽 위(🏆)에 보여 줍니다. 기록을 넘으면 정산 창에 "신기록!"이 뜹니다. DataStore에 저장하므로 Studio에서는 **Game Settings → Security → Enable Studio Access to API Services**를 켜야 서버를 꺼도 남습니다(안 켜면 그 서버에서만 기억).

아직 없는 것: 진행 저장(서버를 끄면 DAY·지갑·빚은 처음부터, 최고 기록만 남음), 실제 게임패스 id, 로비·매칭, NPC 알바생.

## 열고 해 보기

1. `./build.sh`를 실행합니다. 코드를 검사하고 `AnimalKitchen.rbxlx`를 만듭니다.
2. `AnimalKitchen.rbxlx`를 Roblox Studio로 엽니다. **이미 열려 있었다면 저장하지 말고 닫은 뒤 다시 여세요.** 열린 창에서 저장하면 새로 만든 파일을 옛 내용으로 덮어씁니다.
3. 혼자: **Test → Play(F5)**. 여럿: **Test → Clients and Servers**에서 플레이어 수를 2~4로 정하고 Start.
4. 가게는 코드로 짓기 때문에 편집 화면은 비어 있고, 플레이를 누르면 생깁니다.

## 조작

| 키 | 하는 일 |
|---|---|
| WASD | 이동 |
| E | 꺼내기, 집기, 내려놓기, 쟁반에 담기, 손님에게 내기, 버리기, 아이스크림 기계 창 열기, 홀 테이블 빈 그릇 치우기, 개수대에 넣기 |
| F 길게 | 조합대 조합, 토핑 올리기, 소화기로 불 끄기, 개수대 설거지 |
| R | 레시피북 켜기·끄기 |
| C | 카메라 시점: 따라가기(마우스 휠로 확대·축소) → 뒤에서 보기(캐릭터 뒤통수 위, W 앞·S 뒤·A/D 돌기) → 전체 보기 |
| 1~4 | 빠른 말풍선 |
| 오른쪽 아이콘 | 📖 레시피북 · 💬 말풍선 · 🎥 카메라 · 🎵 배경음악 켜기/끄기 · 🆘 끼었을 때 처음 자리로 |
| 관리자 아이콘 | ⏹ 영업 그만하기(영업·튜토리얼 중, 정산 없이 같은 DAY 아침으로) · ⏭ DAY 패스(아침·밤이면 정산 없이 다음 DAY 아침, 영업 중이면 바로 마감하고 정산). Studio에서는 누구나, 실제 서버에서는 게임 주인과 `Config.Admins`의 UserId만 보입니다 |

## 메뉴

| 날 | 메뉴 | 순서 |
|---|---|---|
| 1 | 아이스크림 | 아이스크림 기계(E) → 그릇·맛·토핑 고르기 → 손님 |
| 1 | 밀크티 | 찻잎 + 우유 → 조합대(F) → 티 냄비 → 손님 |
| 2 | 버블티 | 찻잎 + 우유 + 타피오카 펄 → 조합대 → 티 냄비 |
| 3 | 와플 | 반죽 → 조합대 → 와플 기계 |
| 4 | 딸기 생크림 와플 | 반죽 + 딸기 → 조합대 → 와플 기계 → 토핑대(F) |
| 5 | 딸기 케이크 | 반죽 + 딸기 + 우유 → 조합대 → 오븐 → 토핑대(F) |

와플·케이크는 쟁반에 담아서 냅니다. 재료 상자에는 이름표가 붙어 있습니다(잠긴 상자는 천으로 덮고 이름표도 숨김).

와플 기계·티 냄비·오븐 위 막대는 초록(익는 중) → 주황(다 됨, 줄어들면 탐) → 빨강(탐)으로 바뀌고, 와플 기계·오븐에서 탄 채로 두면 불이 납니다. 아이스크림은 꺼낸 뒤 45초 안에 내야 하고, 27초쯤부터 흘러내립니다.

## 코드를 고치며 Studio에 바로 반영하기(선택)

1. 한 번만: `~/.local/tools/rojo-7.7.1/rojo plugin install` (Studio 재시작)
2. `~/.local/tools/rojo-7.7.1/rojo serve`
3. Studio 플러그인 탭 → Rojo → Connect
